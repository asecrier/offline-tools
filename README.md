### [DXF Preflight Shop Pack](https://asecrier.gumroad.com/l/dxf-preflight-shop-pack)

### [Catalog Import Preflight](https://asecrier.gumroad.com/l/catalog-import-preflight)
Importing a product CSV with "Overwrite products with matching handles" can change more than you meant to. Shopify's own help pages say a blank cell in a non-required column replaces the stored value with blank, that changing an option value deletes the old variant ID and creates a new one, and that variant columns without the Option1 columns can create a default variant and delete existing variants. Merchants have posted in the Shopify Community about variants and inventory disappearing after such imports.
